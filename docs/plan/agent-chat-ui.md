# 计划：基础 agent 聊天界面

## 采用的方案

方案 A。前端使用 Element-Plus-X。消息列表用 `BubbleList`，输入用 v2 中替代 `Sender` 的 `XSender`。助手回复按片段追加到同一条消息。

## 改动的目录和模块

- `frontend/`：Vue 3 应用、聊天视图、消息模型和流式输出来源
- `docs/goodCode/`：记录可替换的文本流来源

不改后端，不新增工具、MCP、上下文、人工介入或思考过程的界面。

## 实施步骤

1. 建立 Vue 3 + Vite + Element Plus + `vue-element-plus-x` 前端。
2. 用消息类保存有序片段和状态。这一阶段只渲染 `text`。
3. 发送后追加用户消息和一条 `streaming` 助手消息。本地来源按固定间隔写入同一条文本片段，结束后改为 `complete`。
4. 流式期间禁止再次发送。来源失败时改为 `error`，保留已输出文字，并允许再次发送。
5. 页面只保留消息列表和输入区，并去掉 hover 上浮、位移、放大和阴影抬起。

## 测试范围

- 正常发送后，用户消息和助手消息同时出现，助手文字逐段增长并在结束后完成。
- 空白输入不发送。
- 流式期间第二次发送被拒绝。
- 来源失败后状态为 `error`，之后可以再发送。
- 非文本片段不进入气泡正文。

## 不做的内容

不接后端，不做会话侧栏，不渲染思考过程、工具调用、MCP、人工介入和上下文压缩。
